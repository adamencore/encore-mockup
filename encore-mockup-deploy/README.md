# Encore Audition Platform — Mockup

A clickable visual prototype of the new audition system for Encore Performing Arts.

## What's here

- **Parent view** — what families see (dashboard, audition flow, shows, feedback)
- **Director view** — audition-day tool for directors (notes, ratings, music playback)
- **Admin view** — Encore staff management (shows, cast, content, invoices)

## What this is NOT

This is a **static mockup**. Nothing is functional:

- No real logins
- No data is saved between sessions
- Submissions don't go anywhere
- No real payments processed

The goal is to evaluate **design and flow** before building the real thing.

## How to use

Visit the deployed URL and click "Open parent app" (or director / admin) from the landing page. Navigate around freely — every link works between mockup pages.

## Built with

Plain HTML + CSS + a tiny bit of JS. No frameworks. Hosted on Netlify.
